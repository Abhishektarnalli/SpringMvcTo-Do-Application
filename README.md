# Spring MVC To-Do Application

This is a simple To-Do application built using Spring MVC. It helps to manage daily tasks by allowing users to add, update, view, and delete tasks.

## Features
- Add new tasks  
- View task list  
- Update tasks  
- Delete tasks  

## Tech Stack
- Java  
- Spring MVC  
- JDBC / Hibernate  
- MySQL / PostgreSQL  
- HTML, CSS  

## Project Structure
The project follows MVC architecture with Controller, Service, DAO, and JSP for the frontend.

## How to Run
1. Clone the repository  
2. Open in IntelliJ or Eclipse  
3. Configure the database  
4. Run on Tomcat server  
5. Open in browser
